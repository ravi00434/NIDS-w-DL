INTER-PACKET TIMING
-------------------
16. sinpkt - Source inter-packet arrival time
17. dinpkt - Destination inter-packet arrival time
18. sjit - Source jitter (timing variation)
19. djit - Destination jitter

WINDOW SIZES
------------
20. swin - Source TCP window size
21. dwin - Destination TCP window size

23. dtcpb - Destination TCP base sequence number

TCP CHARACTERISTICS
-------------------

STATISTICAL MEASURES

CONNECTION TRACKING
-------------------

36. ct_dst_src_ltm - Count between destination and source in last time

BEHAVIORAL INDICATORS

37. is_ftp_login - Is FTP login attempt (0/1)

39. ct_flw_http_mthd - Count of HTTP methods in flow
40. ct_src_ltm - Count from source in last time window
41. ct_srv_dst - Count of connections to same service at destination

🔄 NEURAL NETWORK WORKFLOW
===========================

STEP 1: DATA PREPROCESSING
---------------------------
Raw Network Flow → Feature Extraction → Normalization

Example:
Raw: {src_ip: "192.168.1.45", dst_ip: "10.0.0.12", packets: 50, bytes: 2000}
↓
Features: [0.1, 0, 1, 2, 50, 45, 2000, 1800, 500, 64, ...]  (42 values)
↓
Normalized: [0.23, 0.0, 0.33, 0.67, 0.12, 0.11, 0.45, ...]  (0-1 range)

STEP 2: FORWARD PROPAGATION
----------------------------
Input (42) → Dense(256) → BatchNorm → Dropout → ReLU
           → Dense(128) → BatchNorm → Dropout → ReLU  
           → Dense(64)  → BatchNorm → Dropout → ReLU
           → Dense(32)  → Dropout → ReLU
           → Dense(1)   → Sigmoid → Output (0-1)

STEP 3: PREDICTION INTERPRETATION
----------------------------------
Output Value | Interpretation | Action
-------------|----------------|--------
0.0 - 0.3    | Normal Traffic | Allow, log as normal
0.3 - 0.7    | Suspicious     | Monitor closely, possible threat
0.7 - 1.0    | Attack Traffic | Block, generate alert, log incident

🎯 ATTACK DETECTION PATTERNS
=============================

NORMAL TRAFFIC CHARACTERISTICS
-------------------------------
- Low to moderate packet rates (10-100 packets/second)
- Standard byte sizes (500-5000 bytes per flow)
- Common protocols (HTTP=80, HTTPS=443, SSH=22)
- Established connection states
- Low jitter and consistent timing
- Reasonable response times

ATTACK TRAFFIC PATTERNS
-----------------------

DDoS ATTACKS
- High packet rates (1000+ packets/second)
- Small packet sizes (amplification attacks)
- Multiple source IPs to single destination
- Short connection durations
- High connection attempt rates

PORT SCANNING
- Many connections to different ports
- Very short connection durations
- Failed connection states (RST, timeout)
- Sequential or random port patterns
- Low data transfer per connection

DATA EXFILTRATION
- Large outbound byte transfers
- Unusual protocols or ports
- Long-duration connections
- High data rates from internal to external
- Encrypted or obfuscated payloads

MALWARE COMMUNICATION
- Periodic connection patterns (beaconing)
- Unusual destination IPs/domains
- Non-standard protocols
- Encrypted command and control traffic
- Small, regular data transfers

🔍 DECISION MAKING PROCESS
==========================

THRESHOLD-BASED CLASSIFICATION
-------------------------------
```
if prediction >= 0.5:
    classification = "ATTACK"
    confidence = prediction * 100
    action = "BLOCK_AND_ALERT"
else:
    classification = "NORMAL" 
    confidence = (1 - prediction) * 100
    action = "ALLOW"
```
